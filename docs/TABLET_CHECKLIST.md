# 小米平板真机验收

目标设备按用户提供的「小米 Pad 9 Pro Max」记录。未通过 USB 或无线 ADB 连接该真机，不以模拟器结果替代真实猫爪和 HyperOS 验收。请在平板设置的「关于平板」中确认准确型号和 Android / HyperOS 版本。

1. 安装 release APK，离线启动，确认四个玩法和控制项都能显示、滚动和点击。
2. 横向和竖向放置平板，确认内容可访问，游戏目标保持在屏幕内；检查摄像头开孔和导航区域。
3. 「猫爪触摸测试」中先用手指、再用猫爪测试。分别观察轻拍、两爪、滑过、按住以及屏幕保护膜的影响。未上报触摸应记录为硬件识别问题。
4. 从安静观察开始，让猫自愿靠近。观察跟踪、主动出爪、拍中后的继续参与和主动离开；不强迫出爪。
5. 四个主题各测试短场次。检查拍中即消失；爪下不会连续生成目标；声音在默认低音量下柔和可辨认，静音确实不响。
6. 左上角长按后进入小问题；答错回游戏；答对后可继续或结束。普通点击不能直接退出。
7. 切换到桌面或锁屏，返回后应暂停并询问继续；后台不播放反馈声，暂停时间不计入场次。
8. 使用 1 分钟场次检查自动结束和单次记录。退出、重新启动后确认主题、数量、速度、大小和音量保存。
9. 在系统设置查找屏幕固定 / 固定应用，按系统提示启用。测试边缘手势和解除方式；不能仅靠隐藏导航栏判断已锁定。
10. 连续运行 10–15 分钟，记录发热、流畅度、触摸延迟和音效反馈。结束后给猫提供实体玩具和休息。

每次比较尽量只改变一个参数，记录主题、目标数量、大小、速度、有无声音及观察结果。猫的兴趣验证必须由实际猫咪参与。
